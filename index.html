Public Cache Hit

User opens the app; public landing pages & static marketing assets come instantly from the Vercel Edge CDN cache without hitting origin.

Secure API Gateway

Private & dynamic requests travel via TLS 1.3 HTTPS to the Next.js API gateway with auth session & server-derived role check.

3

Rate Limiting Protection

Vercel Firewall & Edge WAF rate limiters block flood bursts, DDoS attacks, and unauthorized bots (returning HTTP 429 Too Many Requests).

4

Serverless Load Balancing

Vercel Edge request routing distributes traffic seamlessly across available Next.js 15 Serverless Function compute instances.

5

Application Compute & Auth

App server validates HttpOnly session cookies, runs strict Zod validation, checks cache headers, and queries the connection pool.

6

Connection Pool & RLS

Supavisor shares pooled connections; PostgreSQL executes queries with RLS returning only allowed tenant rows strictly per role.

Real-Time Engine: 100% Hosted Supabase Realtime (No Custom WebSockets)

Next.js on Vercel runs completely serverless and stateless. All live updates (instant hour approval notifications, live attendance check-ins, and journal updates) connect directly from client browsers to Hosted Supabase Realtime Channels (postgres_changes and broadcast). Zero custom Node.js WebSocket servers or daemons exist on Vercel.
